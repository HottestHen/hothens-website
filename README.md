# Hot Hens website

A simple one-page website: `index.html` (content), `styles.css` (look), `script.js` (small extras).
Every change pushed to this GitHub repository goes live automatically through Vercel within about a minute.

## Common edits (all in `index.html`)
- **Prices / menu items:** search for the item name (e.g. `Baby Cluck S`) and change the text or the `R110` next to it.
- **Sauces:** the "Choose your heat" list and the sauce line-up are both in `index.html`; search for the sauce name.
- **Address, hours, ordering link:** look for the "Find us" section; a comment there shows where they go.
- **Social links / privacy policy:** a comment in the footer shows where to add them.
